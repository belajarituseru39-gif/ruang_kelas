# Ruang Kelas

Aplikasi administrasi pembelajaran (data murid, presensi, asesmen, jurnal, rapor).
Berjalan penuh di peramban tanpa server; data tersimpan di perangkat pengguna.

## Deploy ke GitHub Pages
1. Unggah seluruh isi folder ini ke repositori (index.html harus berada di akar).
2. Settings > Pages > Source: Deploy from a branch > pilih `main` dan `/ (root)` > Save.
3. Buka `https://<username>.github.io/<nama-repo>/`.

Catatan: nama berkas peka huruf besar/kecil di GitHub Pages, jangan diubah.
